File format

Format version 1

A note is a folder. Inside is one Markdown file and the note's photos as JPEGs. There is no database: the Markdown file is the note, and you can read or edit it without the app.

Where notes are

With iCloud Drive on, notes are in iCloud Drive › Shop Capture, which shows up in the Files app, in File Explorer on a Windows PC with iCloud for Windows, and in Finder on a Mac. Without iCloud they are in On My iPhone › Shop Capture in the Files app.

One folder per note

  • The folder is named for the moment the note was started, as YYYY-MM-DD_HHMMSS. The name does not change when you give the note a title.
  • Each photo is named for the moment it was taken, the same way. A second photo in the same second gets -2 on the end.
  • Photos are full-resolution JPEGs, as they came from the camera.

updated: 2026-11-14T08:10:44-06:00

The header

The lines between the two --- lines describe the note.

LineMeaning
titleThe note's title. Left out if the note has none.
createdWhen the note was started.
updatedWhen the note was last changed.
formatThe version of this format. Currently 1.

The # Title heading under the header is a copy of the title, there so the note reads properly in a Markdown viewer. Any other lines you add to the header are kept.

Entries

The rest of the file is the note's entries, in the order they were captured. Each one starts with a marker line and runs until the next marker:

<!-- block TYPE CAPTURED -->
<!-- block TYPE CAPTURED edited EDITED -->

A marker is an HTML comment, so it is invisible when the file is shown in Obsidian or any other Markdown viewer. What you see there is just the text and the photos.

TypeWhat follows the marker
textThe text of the entry.
photoAn image line, ![](photos/NAME.jpg). Any text under the image is that photo's caption.
dividerA line, written as ---.

Times

  • Every time is written in full with the local time zone offset, for example 2026-11-14T07:42:10-06:00.
  • The captured time never changes. It is when the text was added or the photo was taken.
  • If you later change an entry's text, or a photo's caption, edited records when. The captured time stays as it was.

Editing a note outside the app

You can open note.md in any editor. When the app next opens the note it reads the file again, and it is written to keep whatever it finds:

  • Text with no marker above it is kept and shown as an entry of its own, without a time.
  • Text you type under a photo's image line becomes that photo's caption.
  • A marker with a type the app does not know is kept, along with what follows it.
  • A marker that is not well formed, for example one with a mistyped time, is treated as ordinary text and kept.

If two devices change the same note

If a note is changed in two places before they have synced, the app is built to keep both. The other version is saved beside the note as a file named like note conflict 2026-11-14_091544.md, and the app tells you it did so. Nothing is merged or thrown away for you.
